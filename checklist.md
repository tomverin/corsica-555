## Stratégie Terrain

- [ ] Séquence A km 12-42 : early gravel chain. Manger avant km 17, mode warm-up.
- [ ] Séquence B km 137-186 : approche CP1 + point haut. Refill CP1, couches avant descente.
- [ ] Séquence C km 440-462 : climax gravel. Reset complet au km 433, descente avec speed cap.
- [ ] CP1 Ghisoni km 164 : feeding window obligatoire avant montée 10.4 km à +6.1 %.
- [ ] CP2 Crocicchia km 333 : refuel avant descente longue.
- [ ] Km 99-109 : descente paved -6.5 %, temps gratuit si lucide.
- [ ] Km 195-209 : plus longue descente paved, drops OK si propre.
- [ ] Km 253-256 : dirt descent, cocottes, freinage avant courbes.
- [ ] Km 313-316 : short rough descent, vitesse plafonnée.
- [ ] Km 389-411 : corridor mixed track tardif, reset avant entrée.
- [ ] Km 417-419 : descente gravel -8.7 %, marcher si doute.

## Position Et Pilotage

- [ ] Cocottes par défaut.
- [ ] Drops uniquement sur descentes bitume propres.
- [ ] Tops / cintre haut sur longues montées.
- [ ] Off-road : cocottes uniquement.
- [ ] Rotation mains/épaules toutes les 15-20 min sur bitume.
- [ ] Freiner avant les courbes, pas dedans.
- [ ] Priorité sécurité sur descente gravel, chrono secondaire.

## Corps Et Lucidité

- [ ] Genou > 2/10 : ralentir, marcher si besoin, réduire couple.
- [ ] Épaule > 2/10 : changer position, relâcher, mini-mobilité.
- [ ] Nuque tendue : arrêt court, mobilité cervicale.
- [ ] Mains : changer fréquemment, surveiller engourdissement.
- [ ] À chaque arrêt long : check genou / épaule / nuque / lombaires.
- [ ] Hydratation avant les longues montées.
- [ ] Sel / électrolytes toutes les 60-90 min selon chaleur.

## Sommeil / Repos

- [ ] Plan A : pas de sommeil programmé pour objectif 30 h.
- [ ] Micro-rest 5-15 min si lucidité dégradée.
- [ ] Caféine réservée surtout au bloc 02h-07h.
- [ ] S'arrêter avant fatigue extrême.
- [ ] Garder un vêtement chaud sec accessible.

## Mécanique En Course

- [ ] Pression contrôlée après gros choc ou si sensation floue.
- [ ] Crevaison : mèche d'abord, chambre ensuite, boot si carcasse coupée.
- [ ] Plaquettes : contrôle visuel après km 109, 209, 264, 351, 419, 462.
- [ ] Chaîne : lubrifier après pluie / passage rivière / poussière importante.
- [ ] Casse rayon : sécuriser, détendre si besoin, rouler prudent jusqu'au village.

# Priorités De Décision

1. Sécurité et conformité réglementaire.
2. Préservation genou / épaule / nuque / lombaires.
3. Capacité technique sur secteurs gravel.
4. Nutrition, hydratation, chaleur, lucidité.
5. Chrono.

Si deux priorités entrent en conflit, la plus haute gagne.
